# Отключение публичного сайта ermekten.com

Публичное приложение удалено. Telegram-бот, `panel` (`ADMIN_PORT`),
`gateway` (`API_PORT`), остальные сервисы и тома сохраняются.
Конфигурация nginx хранится на сервере вручную, в репозитории её нет.

1. В существующих HTTP/HTTPS-блоках **только для `ermekten.com`** замените
   проксирование сайта и кеширование на `return 410;`. Сохраните SSL-настройки
   и обработчик ACME, если он нужен для обновления сертификата. Пример для
   существующего HTTPS-блока (не полный конфиг):

   ```nginx
   server_name ermekten.com;
   location / {
       return 410;
   }
   ```

2. Удалите `upstream ermekten_site` и `proxy_cache_path` с зоной
   `ermekten_site`, только если больше нет ссылок на них в других блоках.
   Не меняйте виртуальные хосты админки, API и других доменов.
3. Проверьте и примените: `sudo nginx -t && sudo systemctl reload nginx`.
4. Разверните новую версию. Workflows используют `up -d --remove-orphans`,
   поэтому старый контейнер `site` будет удалён. Для локального запуска:
   `docker compose up -d --build --remove-orphans`.
5. Проверьте `curl -I https://ermekten.com` (410), вход в админку и `/start`
   в Telegram. `MINI_APP_URL` в Compose принудительно пустой; бот сбрасывает
   общее меню на команды при запуске, персональное — при `/start` или смене языка.
   Если Mini App отдельно настроен через BotFather, отключите его там тоже.

Настройки `PUBLIC_SITE_URL` для сервиса платежей сохранены без изменений.
Старые браузерные возвраты платежей на сайт после его удаления недоступны.
Исторический план Angular-миграции описывает прежнюю архитектуру.
