# Туры и партнёры в Telegram

Вход: `/partner` или **🗂 Туры и партнёры**. Раздел доступен только в личной
переписке с ботом. `/start` обновляет главное меню у существующих пользователей.

| Было на сайте | Теперь в боте |
| --- | --- |
| Каталог туров | Поиск, даты, направление, длительность, бесплатная отмена, сортировка по датам/цене/рейтингу; подписка на направление |
| Карточка тура | Описание, программа, фотографии, контакты, отзывы, новости и публичная статистика организатора; запись и избранное остаются в прежних разделах |
| Анкета и согласие | Из карточки своей записи: заполнение анкеты и отдельное принятие прежних правил версии v1 |
| Объявления партнёра | Создание, изменение, копирование без дат, удаление с подтверждением; все поля прежней формы, включая место/время сбора и фотографии |
| Группа тура | Участники, статусы и лист ожидания, индивидуальная стоимость, прибытие, анкеты, оплаты/возвраты, расходы и команда; прежняя комната организатора также сохранена |
| CRM | Клиенты, контакты, метки, источник, заметки и история; заявки и их этапы; задачи; шаблоны и рассылки по всем клиентам, метке или группе |
| Отзывы и новости | Просмотр, ответ/изменение/удаление ответа партнёром; публикация новостей с фотографиями; свои отзывы и новости можно удалять |
| Переписка | Чаты с клиентами, организаторами и водителями, история с пагинацией, отправка после просмотра текста |
| Транспорт | Каталог водителей с датой/вместимостью; запрос и отмена транспорта для тура |
| Кабинет водителя | Профиль и видимость в каталоге, автомобили и документы, рейсы, принятие/отклонение заявок, оплаты, расходы и отчёты |
| Статистика и финансы | Сводки, просмотры и обращения за 7/30/90 дней, отчёты за выбранный период, бронирования, баланс и выплаты |
| Награды | Выданные достижения; вручение по коду путешественника с проверкой получателя |

Новые функции используют существующие API и данные. Права и принадлежность
объектов проверяются сервером от имени текущего пользователя; административные
токены не используются. Уведомления о сообщениях и транспорте открывают бот,
а не удалённый сайт. Онлайн-эквайринг не включается этой доработкой.

Формы показывают поля кнопками. Фотографии отправляются по одной и сохраняются
в медиасервисе; секретный Telegram URL никогда не сохраняется в карточке.
Длинные описания и программы можно дополнять несколькими сообщениями.
Сохранение, удаление, рассылка и отправка сообщений требуют явного подтверждения
в интерфейсе бота. Кнопки привязаны к аккаунту и чату, предыдущий экран становится
неактивным; двойное нажатие не повторяет запрос. При ошибке сохранения можно
вернуться к черновику или проверить список перед повтором.

Черновики хранятся в памяти до 30 минут бездействия и теряются при перезапуске.
`/cancel`, выбор другого раздела или `/start` закрывает текущий ввод.
Поддерживаются русский, кыргызский, английский и немецкий языки.

## Проверка и выпуск

- `services/bot`: `go test -race ./...` (с тестовой PostgreSQL для store),
  `golangci-lint run ./...`.
- `services/listings`: `go test -race ./...` с `TEST_POSTGRES_DSN`,
  `golangci-lint run ./...`; проверяются права, CRM, анкеты, транспорт и новые
  callback-кнопки уведомлений.
- Тесты кабинета проходят диалоги через настоящий HTTP-клиент с подписанными
  сессиями: создание/редактирование, сохранность полей, подтверждения, повторные
  нажатия, истечение черновиков, разделение чатов, ошибки API, фотографии,
  вложенные оплаты и анкеты, права водителя, пагинация и локализация.
- Production выпускается только GitHub-тегом `vX.Y.Z`, согласно `AGENTS.md`.
  Миграций БД в этой доработке нет.
